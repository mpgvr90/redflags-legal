# RED FLAGS — legal pages

Privacy Policy and Terms of Use for the RED FLAGS app, in English and Ukrainian, published with GitHub Pages:

- English: https://mpgvr90.github.io/redflags-legal/privacy.html · https://mpgvr90.github.io/redflags-legal/terms.html
- Українська: https://mpgvr90.github.io/redflags-legal/uk/privacy.html · https://mpgvr90.github.io/redflags-legal/uk/terms.html

The pages are generated by `build.py` (no dependencies): edit the texts there, run `python build.py`, commit the HTML.

**Status: draft.** These documents have not been reviewed by a lawyer. They deliberately contain no governing-law or jurisdiction clause; add one only after legal advice.
